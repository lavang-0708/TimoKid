# Phông chữ

**Nunito** (SIL Open Font License 1.1, xem `OFL.txt`), nét tròn, dễ đọc cho trẻ, đủ dấu tiếng Việt. Lấy từ gói `@fontsource-variable/nunito` 5.3.0, ghép hai bộ latin và vietnamese, cắt thành 3 độ đậm tĩnh:

| File | Độ đậm | Dùng cho |
| --- | --- | --- |
| `Nunito-Medium.ttf` | 500 | Dòng tiếng Anh, chữ phụ |
| `Nunito-Bold.ttf` | 700 | Đề tiếng Việt, nút |
| `Nunito-ExtraBold.ttf` | 800 | Số trên nút đáp án, tiêu đề, "Đúng rồi!" |

Phông không có ký tự ⌫: phím xóa dùng `Icons.backspace_outlined`. Ảnh mẫu phối màu: `docs/preview_font_mau.png`.
